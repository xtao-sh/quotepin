# Name and artwork

The application is called 批注工作台 in Chinese and Quotepin in English.

The Apache-2.0 license applies to the source code and documentation unless a
file states otherwise. It does not grant rights to either name, nor to the logo
or icon, as trademarks or branding.

The files `build/icon.png`, `build/icon.icns`, `build/icon-selected-source.png`,
and `public/app-icon.png` are included only so unmodified builds can identify
the application. Forks should use their own name and artwork unless they have
separate permission to reuse these assets.
